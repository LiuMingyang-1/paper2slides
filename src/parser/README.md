# PDF 解析器

浏览器从 `src/parser/index.ts` 导入 `parsePdf(buffer, options?)`。返回值遵循 `Paper`，证据位置使用 PDF 用户坐标，页码从 1 开始。解析器保留调用方的原始 `ArrayBuffer`，可继续用于 PDF 预览。

- `maxBytes` 默认 25 MiB。
- `onProgress(pagesRead, totalPages)` 按页报告文字层读取进度。
- `cropFigures` 在浏览器中默认开启。已有 pdf.js 文档时，可在关闭文档前调用 `extractFigures(pdfDoc, paper)` 更新截图和对应警告。
- Node 评测入口为 `src/parser/node.ts`，使用 pdf.js legacy build。它生成可引用的 caption 和图记录，图记录的 `cropOk` 为 `false`，也没有截图警告。用 `npx --no-install vite-node eval/papers/generate.ts` 重建 JSON。

## 布局和切块

先把水平文字按基线合成行，再用两组重复出现的 x 起点和中间空隙识别双栏。跨栏行切开阅读区间，每个区间先读左栏再读右栏。段落以行距、缩进和字号变化界定。长段落按句拆分，包围框只覆盖该块涉及的行。标题字号、可见字重和编号共同建立章节层级。表格按具有列间距和数字的行识别，公式按数学符号和行形态识别。图注和表注独立保留。

解析器按字号合并第一页的标题行，并用 PDF 元数据和标题下方文字估计作者。重复出现的顶部、底部文字和边缘页码会被移除。致谢从标题或行首标记开始跳过，参考文献从标题开始截断。正文最多保留 40 页，文字层检测可继续读取后面的页面，以区分部分缺字和多数页面缺字。少于 25 个字母、汉字或数字的页视为低文字量。

图截取使用图注上方至相邻正文的区域。双栏区域根据图注和对侧正文判断宽度，渲染后去除明显的分隔线和空白。区域尺寸或像素内容不符合要求时，保留 caption，设置 `cropOk=false` 并记录 `FIGURE_CROP_FAILED`。

## 构建和限制

浏览器入口以 Vite 的 `?url` 导入同源 worker，将标准字体和 CMap 编入 JS，由 pdf.js 在需要时解码。当前主入口仍是 T5 占位页，因此分支的标准构建只产出占位页。在同配置的临时副本中让主入口调用 `parsePdf` 后运行 `npm run build`，可在 `bundle/assets/` 中看到 `pdf.worker.min-*.mjs`。合入 T5 时由其入口导入解析器。

扫描 PDF 需要先获得可提取的文字层。三栏、竖排、边栏、跨页段落、缺少可靠文字映射的 PDF，以及不规则的表格和公式，仍可能出现漏切或顺序错乱。证据包围框精度为行级。横向或上方图注、相邻图片、弱对比度图，以及缺少明显栏边界的组合图，可能触发回退或产生不完整截图。
