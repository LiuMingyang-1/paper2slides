# Paper2Slides 提示词

提示词源文件由 `npm run prompts` 编译为 `src/prompts/generated.ts`。构建时将公共规则内联，运行时填充变量；应用运行时无需读取 Markdown。修改模板、共享规则或输出预算时，递增所有受影响提示词的版本，确保缓存失效且调用日志可追溯。

| 提示词 | 职责 | 单次输出上限 |
| --- | --- | --- |
| `01-understand.md` | 读整篇证据并提取实际存在的模块。长文先按章节生成短摘要，再合并。各阶段保留原始证据 ID。 | 4,096 tokens；章节及中间合并为 2,048 |
| `02-outline.md` | 按用户侧重点产出 5–8 页，首项为标题页。只使用已识别的模块，为内容页写检索意图，需要时指定可用原图。 | 1,536 tokens |
| `03-slide.md` | 用检索证据和大纲项填充一页。版式槽位上限由代码注入，匹配原图可用性，每条正文要点带来源和类型。 | 1,536 tokens |
| `04-compress.md` | 缩短渲染后指定的溢出槽位。保留要点数量、引用、数字写法、版式及未溢出的内容。 | 1,536 tokens |

四条提示词使用 `language=zh/en`，并各自提供反例。`_shared/citation-rules.md` 约束原文、数字和引用。`_shared/output-schema.md` 约束 JSON 格式。字符串槽位放标签或书目信息，表格正文和关键数字用可核验要点。模型返回不存在但格式正确的证据 ID 时，保留原 ID 并在调用日志记录，由核验环节展示问题。

## 调用估算

5–8 页、无缓存且无重试时，理解与大纲各 1 次，每页 1 次，共 **7–10 次 completion**。按设计文档中正文约 10k–25k tokens、逐页检索及固定提示词估算，输入约 **20k–70k tokens**，总输出预算上限为 **13,312–17,920 tokens**。这是根据文本长度与配置得出的估算，尚未用真实模型测量。检索器的 embedding 调用另计。长文用章节、必要的中间合并和最终理解替换一次整篇理解。每次页面压缩另计 1 次，重试也分别记账。
