# T16 上传 PDF 内容来源评测

基于 `8b78739`。用 Anna staging 的 Paper2Slides harness 和平台分配的 `xiaomi/mimo-v2.5`，逐篇上传 PDF、理解、生成大纲和幻灯片、核验、导出 PPTX。使用默认的中文、均衡侧重点与 BM25。基线使用 [run7 的 BERT 调用日志](../runs/2026-11-21/run7/calls.json)、[逐页截图与核验文字](../runs/2026-11-21/run7/) 和 [核验审计](../runs/2026-11-21/run7/verify-audit.md)。run7 是历史基线，生成有随机性。

## 方法

- BERT 使用 [替换表](bert-tamper.json) 与 [PDF 生成器](tamper-pdf.py)。生成器先核对原 PDF 的 SHA-256，再在原页面擦除并重排目标文字，保留布局、图形和页面编号。每条规则都有预期命中数，共修改 58 处。用 Poppler 检查整篇可提取文本，再用产品的 PDF.js 解析器复核实际入管线的[证据](../runs/2026-11-21/grounding-tamper/parsed.json)。原 BERT 样本按 CC BY 4.0 提供，改动记录在替换表中。[原论文与许可信息](../papers/README.md)
- 评测脚本只负责生成和选择一个 PDF 文件。篡改版走普通上传路径，四个环节均接收该文件的解析证据，共用文档哈希与缓存逻辑。脚本和替换表没有应用侧入口，Vite 生产包中查无 `--tamper`、篡改文件名、新术语及额度守卫字符串。浏览器解析取正文前 9 页，整份上传文件有 16 页。附录中的对应原值同样修改。保留 SST-2 的 93.2、MRPC 的 86.7，以及作为其他消融设置出现的 80%。
- 将有上下文的事实作为计数单位。GLUE 总分和领先分差合为一项，ASP 全称、中文翻译和缩写合为一项。列出正文、标题与讲稿中出现的值，说明是否可逐条核验。采用反事实值证明这项输出对上传证据敏感。出现原值记为与模型记忆一致的污染信号，单次输出无法确定内部成因。
- 引文有效率采用存在的引用 ID 数除以引用 ID 总数。引文支持率按 [DESIGN §7](../../docs/DESIGN.md#7-评测) 使用被应用判为 ✅ 的要点数除以已核验要点数。另列人工引文支持率，逐项判断所引片段能否支撑完整陈述。数字准确率按有语义的数字出现次数算，忽略装饰页码与引文序号。版本、层数、日期、样本数量等保留上下文逐个核对。
- 各次额度用调用日志中的 `quotaConsumed` 精确求和，包含有额度的格式重试。35 额度上限在本地 dashboard 的模型请求发送前做保守预留，收到额度后再结算。耗时按端到端 UTC 时间戳计算，包含上传、截图和导出。工作树目录名为 UUID，启动时显式传入 `--slug paper2slides`。

## 发现的问题与边界

- BERT 第 9 页的表格将真实数字放到错误的指标列。以首行为例，`e8-4` 表里的 BERTBASE MRPC 为 86.7，SQuAD 为 88.5，SST-2 为 92.7。成稿的 MRPC 列写 88.5，SQuAD 列写 92.7，仍判 ✅。可为表格核验增加列名与行名约束，并检查数值和基准的配对。
- 两篇中文成稿有不少人工确认的引文被应用判为 ⚠️，也存在引用 ID 存在、实际引文只支持句子一部分的 ✅。可以用这里的人工样本量化跨语言误判，并补完整段落拆块后的相邻引文。摘要和讲稿等字符串槽位只做有限校验。BERT 的 70/20/10 和 50/50 简写可以作为比例识别的新增对照。
- 可视化论文首页的边栏与正文被交错切块，综述的公式也被拆成多个证据块。T17 在证据文本和 PPTX 导出时过滤 XML 1.0 禁用字符，并在端到端导出校验中解析 PPTX 包内的 XML 部件。
- 三篇各一份成稿，覆盖率、内容质量和生成稳定性仍会受论文版式、证据选择与生成随机性影响。手工支持率来自每篇不同页的定向抽查，无法据此估算全稿的精度。BERT 的反事实命中直接显示上传 PDF 对所测输出的影响，适用结论限于实际呈现的事实。

复现 BERT 篡改评测可运行以下命令。需要在评测环境安装 `pymupdf==2.1`，并按 [E2E 文档](../e2e/README.md) 启动本地 harness。

```sh
node eval/e2e/real.mjs --pdf eval/papers/bert.pdf --tamper eval/grounding/bert-tamper.json \
  --out /tmp/grounding-tamper --quota-limit 35
npx --no-install vite-node eval/grounding/parse-source.ts \
  /tmp/grounding-tamper/input-tampered.pdf /tmp/grounding-tamper/parsed.json
npx --no-install vite-node eval/grounding/verify-original-values.ts /tmp/grounding-tamper/parsed.json
```

检查通过 `npm run typecheck`、`npm test`（204 项）、`npm run build`、`anna-app validate`。本地评测 harness 已关闭。
