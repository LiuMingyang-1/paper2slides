# 前端重设计：苹果风格（2026-11-21）

> 范围：只改 App 外壳（顶栏、步骤、上传页、大纲页、预览工作台、引用气泡、核验面板、对话框）。**幻灯片主题（`src/layout/slide.css`）和 PPTX 导出不动。**
> 参考：项目内 skill [`.agents/skills/apple-design/SKILL.md`](../.agents/skills/apple-design/SKILL.md)（Apple WWDC 设计原则的 Web 版）。

## 1. 原则

- **简单不等于极简**：最重要的操作最显眼（每页只有一个主按钮），次要操作退一层。
- **克制**：一个强调色，其余用中性色；靠留白、字号、字重建立层级，不靠边框和底色。
- **材质表达层级**：浮在内容之上的东西（顶栏、工具栏、气泡）用半透明毛玻璃；内容区用实色卡片。
- **反馈即时**：按下即有反馈；动效短、不打断操作；尊重系统无障碍设置。

## 2. 设计令牌

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#F5F5F7` | `#000000` | 页面背景 |
| `--surface` | `#FFFFFF` | `#1C1C1E` | 卡片、面板 |
| `--surface-2` | `#FBFBFD` | `#2C2C2E` | 输入框、次级面板 |
| `--label` | `#1D1D1F` | `#F5F5F7` | 主文字 |
| `--secondary` | `#6E6E73` | `#98989D` | 次要文字 |
| `--separator` | `rgba(60,60,67,.12)` | `rgba(84,84,88,.6)` | 细分隔线（少用） |
| `--accent` | `#0071E3` | `#0A84FF` | 唯一强调色：主按钮、链接、选中态、角标 |
| `--green` / `--orange` / `--red` | `#34C759` / `#FF9500` / `#FF3B30` | `#30D158` / `#FF9F0A` / `#FF453A` | 核验 ✅ / ⚠️ / ❌ |
| `--material` | `rgba(255,255,255,.72)` + `blur(20px) saturate(180%)` | `rgba(28,28,30,.72)` 同上 | 毛玻璃 |

- 圆角：卡片 18px，面板 14px，输入框 10px，按钮胶囊（999px），小标签 6px。
- 阴影：只用很淡的两层，例如 `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`；浮层（气泡、对话框）更深。
- 间距：8px 基准网格；rem 单位。
- 深色模式：`prefers-color-scheme: dark` 自动切换。若 Anna host 传入 `themeMode`/`theme`（harness URL 里有 `theme=light&themeMode=system`），优先跟随 host。

## 3. 字体

- `font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`；等宽数字用 `font-variant-numeric: tabular-nums`，不再用衬线和等宽字体做装饰。
- 层级：大标题 40–48px / 600 / `-0.02em` / 行高 1.08；页面标题 28px / 600 / `-0.015em`；分组标题 17px / 600；正文 15px / 400 / 行高 1.5；说明 13px / `--secondary`。

## 4. 组件

| 组件 | 设计 |
|---|---|
| 顶栏 | 吸顶毛玻璃，高 52px，左侧品牌（简洁图标 + "Paper2Slides"），右侧额度、调用日志、中英分段控件；滚动后底部出现柔和渐变遮罩而不是实线 |
| 步骤指示 | 居中三段式，当前步为强调色实心圆点 + 粗体，完成步为对勾；或做成分段控件样式。保持可读的 `aria-current` |
| 按钮 | 主按钮：强调色胶囊、白字；次按钮：浅灰填充胶囊（`rgba(120,120,128,.12)`）；文字按钮：强调色文字无底色。`:active` 时 `scale(.97)`，100ms |
| 分段控件 | 中英切换、汇报侧重点（均衡/方法优先/实验优先）改为分段控件 |
| 上传页 | 大标题 + 一句副标题居中；上传区为大圆角白卡片，虚线改为柔和描边，拖入时强调色描边 + 轻微放大；Demo 卡片与之并列或下方，同风格 |
| 大纲页 | 左侧大纲列表做成 iOS 设置式分组列表（圆角卡片内的行，行间细分隔线，拖动/上下移动/删除为图标按钮）；右侧论文理解卡片；额度预估为浅色信息条 |
| 进度 | 细的强调色进度条 + 当前阶段文字，不用默认 `<progress>` 外观 |
| 预览工作台 | 三栏：左缩略图（选中项强调色描边 + 轻阴影），中幻灯片（放在浅灰画布上、带投影，像 Keynote），右 PDF；栏之间留白分隔而不是边框；顶部工具栏毛玻璃，"导出 PPTX" 为唯一主按钮 |
| 核验面板 | 三个计数做成彩色小胶囊（绿/橙/红 + 数字）；失败项列表为分组列表行，左侧状态色点 |
| 引用角标与气泡 | 角标为强调色小上标；气泡为毛玻璃浮层，从角标处 `transform-origin` 弹出（opacity + scale .96→1，150–200ms），状态用彩色小标签 |
| 对话框（调用日志） | 居中大圆角面板，背景暗化遮罩；等宽字体仅用于 JSON 内容 |
| 错误/警告 | 圆角信息条，左侧状态色图标，不用整块高饱和底色 |

## 5. 动效与无障碍

- 页面/步骤切换：opacity + 8px 位移，200–250ms，`cubic-bezier(.2,.8,.2,1)`；不锁输入。
- `prefers-reduced-motion: reduce`：只保留淡入淡出。
- `prefers-reduced-transparency: reduce`：毛玻璃改实色。
- `prefers-contrast: more`：实色背景 + 明确描边。
- 保持现有焦点样式的可见性（改为强调色 focus ring），对比度达到 WCAG AA。

## 6. 约束

- 只改 `src/ui/`（以 CSS 为主，必要的 DOM 结构/类名调整）和 `index.html`；不改 `src/layout/`、`src/export/`、管线和核验逻辑。
- 不引入新的运行时依赖和外部字体/资源（CSP `connect-src 'self'`，bundle 不能访问外部域名）。
- 不改变文案和交互流程；`src/ui/strings.ts` 只在必要时新增。
- 现有测试和 e2e 脚本依赖的按钮文字（"理解论文并生成大纲"、"生成幻灯片"、"导出 PPTX"、"调用日志"、"试用 BERT Demo"、"下载 PPTX"、"更换论文"）保持不变。
